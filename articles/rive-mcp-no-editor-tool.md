Rive、UIアニメーションのツールとしてはかなり気に入って使っているんですが、.rivファイルをプログラムから直接いじる手段がほぼ無くて困っていました。公式のMCPサーバーはエディタが起動していることが前提だし、サードパーティのものは有料。「.rivさえあれば動く、なんならAIに最初から.rivを作らせたい」というのが動機で、バイナリフォーマットを自分で解析してMCPサーバーを書きました。rive-mcpという名前で公開しています。

https://github.com/ODU33104/rive-mcp

npmでも入れられます。

```bash
npm install -g rive-mcp-server
claude mcp add --scope user rive -- rive-mcp
```

あとはClaudeに日本語で「跳ねるボールのrivを作って」とか頼むだけで、.rivバイナリを直接生成してプレビューまで返してくれます。

## 何ができるか

ツールは全部で19個ありますが、大きく分けると

- 生成: JSONでシーンを指定すると.rivに変換する`riv_create`、キャラのPNG1枚からリグ済み.rivを作る`riv_rig_character`
- 編集: プロパティやテキストの変更、キーフレームの追加・削除まで無損失でできる`riv_edit`
- 解析: `riv_inspect`や`riv_dump`、`riv_diff`など中身を覗くツール一式
- 出力: PNG、GIF、透過対応のAPNG、WebM動画、スプライトシート
- 実行: ステートマシンに入力を送って遷移を確認できる`riv_play_state_machine`
- 統合: React/Vue/Svelte/Flutter向けの組み込みコードを吐く`riv_generate_code`
- UI: ローカルで動くWebスタジオ`riv_studio`

レンダリングは公式ランタイム（`@rive-app/canvas-advanced`のWASM）をheadless Chromiumで動かしているので、見た目は本番とまったく同じです。自前でレンダラを実装するのは怖かったので、ここは公式に乗っかっています。

## 実装で苦労した点

一番厄介だったのは.rivのバイナリを直接組み立てるところです。typeKeyとpropertyKeyベースの可変長フォーマットで、型定義自体は公式ランタイム（rive-runtimeリポジトリ、MIT）から機械的に抜き出して同梱しました。ただ、オブジェクトの親子関係やキーフレームがどのオブジェクトに属するかが、明示的なIDではなくバイトストリーム上に出てくる順番で決まっていて、これに気づくまでかなり時間を溶かしました。挿入や削除のたびにインデックスを付け直す必要があって、riv_editの実装はほぼこの処理に費やしています。

APNG出力も地味に苦労しました。GIFは256色までしか出せないし透過も苦手なので追加したんですが、画像デコードは一切せずに、レンダリング済みのPNGフレームからチャンク（IHDR/IDATあたり）だけ抜き出してacTL/fcTL/fdATを組み立て直すとAPNGになります。CRC32だけ自前で書けば、あとはNode標準の機能で完結しました。

あとローカルのWebスタジオには「AIへの指示」を書くボックスがあって、人間がブラウザ上で修正依頼を書くとAIがそれを拾って`riv_edit`で直す、というループを作りました。キャンバス上でのドラッグやリサイズ、キーフレームのタイムライン編集、Undo/Redoも一通り実装したので、大枠はAIに作らせて微調整は人間が手でやる、みたいな使い方ができます。

## 制約

無料で使えますがOSSではなく、source-availableというライセンスです（改変や再配布は不可、生成物の利用は自由）。あとLuauのスクリプティングとLayoutエンジンはまだ対応していません。ランタイム側の仕様がまだ固まっていない印象なので、様子見しています。Rive, Inc.とは関係のない非公式のツールです。
